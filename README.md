EduLearn Online School

A modern, responsive online learning website demonstration built using HTML, CSS and JavaScript.

Project Overview

EduLearn is a demonstration educational website designed to present online courses through an attractive and accessible interface.

Features

- Responsive navigation
- Course catalogue
- 12 demonstration courses
- Course search
- Category filtering
- Course information cards
- About section
- Student enquiry form
- Contact section
- Responsive design

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- "index.html" – Website structure
- "style.css" – Styling and responsive layouts
- "script.js" – Interactive functionality
